Syntax Guide

Break your work into cells using the tags below. Each cell starts on a new line.

Math cell — # %%

Equations are calculated and rendered as professional LaTeX. Variables carry over to later cells.

# %%
L = 6.0 * m
M_max = (w * L**2) / 8
code_check(M_max, M_cap, "Moment Check")

Text cell — # %% md

Markdown text. Use # for headings, **bold**, --- for dividers.

Plot cell — # %% plot

Define a function of x, then call draw_bmd(func, L) or draw_sfd(func, L).

# %% plot
def M(x): return (w * x / 2) * (L - x)
draw_bmd(M, L)

Solver cell — # %% solve var = guess

Numerically solves for a variable. Write the equation with ==. Include units in the guess.

# %% solve L_max = 1.0 * m
M_cap == (w * L_max**2) / 8

Summary cell — # %% summary

List variable names (comma-separated) to generate a results table.

# %% summary
L, M_max, M_cap, V_max
